该部署尚未配置管理 token

当前 keyserver 未设置 MS_KEY_ADMIN_TOKEN，管理接口整体关闭（无 loopback 放行 —— frp 同机部署形态下来源 IP 恒为 127.0.0.1，放行等于公网裸奔）。

请在 keyserver 所在机器设置环境变量后重启服务，再访问本页：

MS_KEY_ADMIN_TOKEN=<随机长 token>    # 管理端（本页）token
MS_KEY_CLIENT_TOKEN=<随机长 token>    # 消费端 token（frp 部署双 token 必设）

本机开发调试可临时用 MS_KEY_DEV=1 逃生（仅 token 未配置时生效）。
