## 〇、一句话结论（v2）

**90%+ 在 M1787（牛仔裤 8 码套排）上可达：sparrow + v0.3 公差多 seed 实测 max 90.38%（mean 89.36%，std 0.72pp），单 marker 几何已能碰到 90——但 sparrow 对 seed 敏感不稳，破 90 的主手段是多 seed 重启取优 + 真实约束引擎比 erode 更紧（分床已被版师排除）。** 路线 = **复用 sparrow 算法核（MIT 许可、已证 85.8%）+ 自研 v0.3 约束层把重合/旋转公差可控注入**。自研工作从"2–3 月死磕 GLS 追平 14pp"收窄到"2–4 周做约束层"——约束层是 sparrow 设计上不做、本项目真正有壁垒的地方。最大风险是 erode 预处理的产品化合法性（[§五.3 阶段 1](#阶段-1erode--产品化合法性验证1--2-天最大风险--关键分叉点)），**先验证再投入**。

## 一、90% 到底可达吗？（三路交叉验证）

| 来源 | 数据 | 可信度 |
|---|---|---|
| 学术 SOTA sparrow 2025（arxiv 2509.13329）| {0/180} 约束下 **TROUSERS 92.62%**、SHIRTS 90.92%、MARQUES 92.0%、FU 92.4% | ★★★ 论文 Table 3 |
| 商业软件（Gerber/Lectra/Optitex）| 典型 **82–88%**，"90%+"多有营销成分（忽略门幅切边） | ★★ 行业基准 |
| 顶级牛仔工厂实际 | **92–96%**（梭织/牛仔，人工+超排配合） | ★★ diznew 行业资料 |
| 本项目 stage1c | 71.9%（位图+弱SA） | ★★★ 实测 |

**结论**：
- {0°,180°} 姿态**不是**物理上界——之前怀疑的"71.9% 已接近 0/180 极限"**是错的**，那是弱算法的结果，不是约束的极限。
- 现实目标 **82–88%**，stretch goal **90%+**。
- 90%+ **强依赖款型互补性**：M1787 直筒款的裆弯曲线复杂度决定天花板，需跑一次实证才知道是 88 还是 92。
- 学术基准形状简单（整数顶点、无曲线/剪口），真实服装要再扣 **3–8pp**。

## 二、为什么卡在 72%？（瓶颈定位）

当前引擎 = **位图 FFT NFP（2mm/像素）+ BLF 贪心 + 弱 SA（40 次迭代/单邻域/只换片序）**。

三路调研一致定性：**位图 NFP 是学术 SOTA 的反面教材**（Guo 2022 review §3.1 明列三大缺陷：精度上限、内存、无法表达非正交边——正好全撞牛仔裤裆弯/口袋斜边曲线）。

四个瓶颈（按影响排序）：

| # | 瓶颈 | 现状 | SOTA 做法 | 预期收益 |
|---|---|---|---|---|
| 1 | **弱 SA** | 40 次/单邻域/只换片序 | GLS（item-pair weights）+ 迭代改进 | **+5–8pp** |
| 2 | **缺迭代改进范式** | 一次性贪心放 | "临时允许重叠 + GLS 逐步消除碰撞" | +2–3pp |
| 3 | **位图精度** | RES=2mm，曲线互锁缝隙被像素吃掉 | 精确几何 NFP（Minkowski 和） | +1–2pp |
| 4 | **预组块废弃 + 缺填缝** | 单片 FFT 排，小片不塞缝 | 两片配对组块 + 小片填缝 | +2–3pp |

> 瓶颈 #1/#2（SA 强度 + 迭代范式）是大头，精度只占 1–2pp。**v2 决策**：既然算法强度是主因，而 sparrow 已是开源 SOTA 且可直调——直接复用 sparrow 拿到这 14pp，不自研。

## 三、最关键的洞察：sparrow 范式与 v0.3"重合公差"同源

sparrow（开源 SOTA，服装基准 90%+）的核心算法：

> **分解为 feasibility 问题序列 → 临时允许重叠 → Guided Local Search 引导逐步消除碰撞**

本项目 stage1c "重合公差排料"：

> **内外档允许重叠 5–10mm（v0.3 规则）→ 排料时允许重合**

**两者思路完全同源**——本项目已站在 sparrow 的方法论上，只是把"精确几何 + GLS"降级成了"位图 + 弱 SA"。

**硬约束**：sparrow 设计上**排斥任何接触**（"items will always be completely separated, if only by a minuscule distance"），与服装内外档重合 5–10mm 冲突。**所有开源引擎都不支持"指定片对重合 d 毫米"的服装公差语义**——约束层永远必须自建（v0.3 + 模板库 1b 已有，这是护城河）。

→ **v2 结论**：算法核借 sparrow，约束层自研。两者结合点 = 把 v0.3 公差"伪装"成 sparrow 能消化的输入（预处理 erode）+ 排完再校验（后处理 pyclipper）。

## 五、方案 v2：hybrid（sparrow 算法核 + 自研 v0.3 约束层）—— 当前执行

### 5.1 战略转向：为何从 B 路径 GLS 转 hybrid

定 B 路径时（v1），sparrow 还只是"论文里的 SOTA"。三实验跑完后，前提变了：

1. **sparrow 现可直接调用**（`pip install spyrrow`，Windows cp311 wheel，无需 Rust），**MIT 许可可商用**。
2. **三实验已证 sparrow + v0.3 公差 ≈ 90%**：baseline 85.79% / erode10 89.77% / v0_rot 87.55%。
3. 自研 GLS 要追平的，正是 sparrow **最复杂**的部分（采样 + coordinate descent + GLS 权重 = 那 14pp），是 2–3 月硬工程。

→ **算法强度这 14pp，复用 sparrow 直接拿到；自研精力投到 sparrow 不做、本项目有壁垒的约束层。** 这不是推翻 B 路径的调研结论，是同一调研在新数据下的更优解。

### 5.2 新架构（数据流）

```
DXF 裁片输入
  → [自研·预处理] 按 v0.3 规则给每片生成配置：
        内部片 → 腐蚀量 d（按片型）+ 旋转集（版师确认的 8–45°）
        外部片 → {0,180} 硬约束 + 0.4mm 公差               ← 护城河
  → [sparrow] 排料求解（anytime，2min 出图，实验①证 2min→85.23%）
  → [自研·后处理] 恢复原轮廓 + pyclipper 精确校验重叠合法性
        + 非法重叠局部修正（若阶段 1 证明需要）
  → DXF/SVG 排料图输出（复用 run_1c.export）
```

- **算法强度**：白嫖 sparrow（85.8% 已证）
- **差异化武器**：v0.3 重合（+4pp）+ 旋转（+1.8pp）可控注入
- **校验**：pyclipper 精确几何（原 2c 降级为校验层，符合方向文档修正 1）

### 5.3 分阶段（每阶段可独立验证）

#### 阶段 0：钉死可达性（半天，纯验证）⬅ 当前

- **实验④**：erode10 + v0_rot **组合**跑 sparrow（内部裁片腐蚀 10mm + 自由旋转，外部 {0,180}）
- 复用 `sparrow_experiments.py`，新增 `erode_rot` 配置
- 目标：确认 ≥ 90% → 把"M1787 上 90% 可达"钉死
- 不改架构，只是把单变量结论合成

#### 阶段 1：erode → 产品化合法性验证（1–2 天，**最大风险 + 关键分叉点**）

**这是从"实验成立"到"产品成立"的关键一跃。**

实验③的 erode 是**统一腐蚀所有内部片 10mm**，但 v0.3 规则是**特定片对（内外档）允许重合**。sparrow 不知道工艺语义——它排的是腐蚀后的小片，恢复原轮廓后每对相邻内部片会侵入 ~10mm。**问题：这些重叠是否都落在 v0.3 允许的片对集合内？** sparrow 可能把两个本不该重合的内部片也排相切，恢复后就成非法重叠。

拿阶段 0 的解做三件事：
1. 恢复内部裁片原轮廓，用 pyclipper/shapely 算出所有重叠片对 + 重叠量
2. 比对 v0.3 允许集合（内外档重合）+ 公差量（内部 5–10mm、外部 0.4mm）
3. 量化：合法重叠占比、非法重叠的片对数 / 量级

**分叉结论**：
- 非法重叠少且小 → erode 预处理路径成立，阶段 2 走**轻量约束层**（预处理 + 校验）
- 非法重叠多 → 需后处理局部精修，约束层变重；极端情况 erode 路径不成立，回退评估（[§十](#十历史v1--b-路径-gls-自研已被-hybrid-取代)）

##### 阶段 1 实测结果（2026-08-08 完成）：**erode 路径合法，走轻量约束层**

脚本 `nesting_engine/nest_stage1_legality.py`：跑 erode10+rot seed3（90.38% 那个解），恢复内部片原轮廓，shapely 算所有片对重叠。**penetration 主指标用重叠区 bbox 短边（垂直侵入深度）**——长边对细长片平行搭叠会严重高估（如"双排叠前片"长边 127mm 但真实侵入仅 8.8mm）。

| 类别 | 对数 | 真实侵入深度 min/med/max | 判定 |
|---|---|---|---|
| 外-外 | **0** | — | 健全性 ✓（外部未腐蚀 + sparrow 无碰，变换无 bug） |
| 内-外 | 63 | 0.2 / **4.3** / **8.8** mm | **全部 ≤10mm，0 对 >10mm**；全是"内部片边缘浅搭外部片窄带"，服装工艺缝纫叠门常规 |
| 内-内 | 8 | 2.0 / **14.8** / 19.4 mm | 7 对 >10mm（buffer(-d) 非均匀内缩致凸出外扩超 d，非 bug） |

**合法化代价（面积下界，乐观）**：内-外 超公差推开多用 9.8mm + 内-内 超限推开多用 2.7mm = **~1.25cm 用布**，701.5→702.7cm，**90.38% → ~90.22%（-0.16pp），仍 ≥90%**。

**结论**：erode 路径的高利用率**是真实的**，不是靠非法重叠换来的虚假数字。**阶段 1 验证通过 → 走轻量约束层**（erode 预处理 + 后处理校验/局部推开），无需自研真实约束引擎（B 路径 GLS 彻底排除）。

**两个待版师拍板（不阻塞，定约束层轻重）**：
1. 内-外 浅搭（4–9mm）工艺是否认可？（大概率是——内部片本就要叠外部片缝）
2. 内-内 上限放 ~15–20mm？或 erode d 10→8（侵入降到 ~12mm）

产物：`_output/stage1_legality/legality_*_s3_d10.{json,svg}`

## 六、sparrow 实证（baseline + 三实验 + 阶段 0）

### 6.1 baseline + 三实验（2026-08-06/07，已跑完）

M1787 128 片，各 600s，seed=0，density 用**原面积口径** total_area/(used_mm×gate)（腐蚀只影响排料紧度不缩面积）。

| 实验 | 配置 | real 密度 | 用布 cm | vs baseline |
|---|---|---|---|---|
| baseline | {0,180} 不腐蚀 | 85.79% | 739.0 | — |
| ② v0_rot | 外 {0,180} + 内自由旋转 | 87.55% | 724.1 | **+1.76pp** |
| ③ erode5 | {0,180} 内部腐蚀 5mm | 88.14% | 719.3 | **+2.35pp** |
| ③ erode10 | {0,180} 内部腐蚀 10mm | **89.77%** | 706.2 | **+3.98pp** |

**实验① 时间曲线**：600s→85.79%，3600s→85.81%（+0.03pp），且 3600s 在 592s 自行早停 → **85.8% 是 {0,180}+无重合 的硬收敛值，时间不是瓶颈**。anytime 2min 已到 85.23%，"2 分钟出图"现实。

**三个结论**：
1. **重合公差是 90% 最大单一杠杆（+4pp）**——erode10 单独推到 89.77%，距 90% 仅 0.23pp。校准了"内部裁片面积小（仅 4.9%）收益有限"的担忧：内部裁片是填缝配角，腐蚀后塞进大裁片缝隙。
2. **旋转公差 +1.76pp，可观但非主力**。
3. **90% 实证可达**——重合（89.77%）+ 旋转（+1.76pp，部分重叠）组合大概率破 90%。

### 6.2 阶段 0 组合实验（2026-08-08，已跑完）

erode10 + v0_rot 同跑（内部裁片腐蚀 10mm + 自由旋转，外部 {0,180}，600s 预算 / 305s 早停）：

| 实验 | real 密度 | 用布 cm | 说明 |
|---|---|---|---|
| baseline {0,180} | 85.79% | 739.0 | 算法基线 |
| erode10 单独 | 89.77% | 706.2 | 重合杠杆 |
| v0_rot 单独 | 87.55% | 724.1 | 旋转杠杆 |
| **erode10+rot 组合** | **89.83%** | 705.8 | **阶段 0 结果** |

**两个关键结论（与预期不同）**：
1. **组合 89.83%，没破 90%**（差 0.17pp / 1.2cm）。重合+旋转单 marker 几何上界 ≈ 89.8%，比"组合大概率破 90"的预期保守。
2. **旋转收益被重合吃掉**：erode10 单独 89.77% vs 组合 89.83%，旋转的 +1.76pp 几乎没叠加。印证方向文档修正 3"收益重叠"——重合和旋转都改善"内部裁片填缝"这同一空间，不累加。

**90% 的剩下路径**（单 marker 几何手段已近上界，需别的维度）：
- ~~分床 / cut-order~~：**版师 A 已否决（不分床）**
- 真实约束引擎比 erode 更紧（阶段 1/2）：erode 是统一缩小，可能损失合法的更紧排列，+0.x pp
- 多 seed / 参数微调：碰运气，不稳（可作低成本试探）

### 6.3 多 seed 试探（2026-08-08，5 seed × 600s）

| seed | real 密度 | 用布 cm |
|---|---|---|
| 0 | 89.83% | 705.8 |
| 1 | 89.20% | 710.7 |
| 2 | 88.23% | 718.6 |
| **3** | **90.38%** ✅ | 701.5 |
| 4 | 89.17% | 711.0 |

min 88.23% / max **90.38%** / mean 89.36% / std **0.72pp** / 破 90：**1/5**

**两个结论**：
1. **90% 几何可达**（seed 3 = 90.38%，用布 701.5cm）——证实单 marker 内能碰到 90，修正"89.8 天花板"的判断。
2. **但 sparrow 对 seed 敏感、不稳**：std 0.72pp > 破 90 的 0.17pp gap，单次跑破 90 概率约 20%（1/5）。mean 89.36%。

**破 90 的解药 = 多 seed 重启取优**（anytime 标准增强）：跑 N 个 seed 取利用率最高的，产品可稳定输出接近 max（90%+）。必做的产品化增强。

| **多 seed 重启取优** | ✅ **破 90 主手段**（seed 3 已证几何可达） |

**最终结论**：版师工艺框架（不分床、码号客户定）锁死外部增量后，90% 靠"多 seed 重启取优"稳定逼近 + "真实约束引擎比 erode 更紧"再凑一点。**90% 可达、需工程化（多 seed），不是天花板问题。** 版师 C（任意内部片对可叠）让 erode 完全合法 → 阶段 1 走最轻路径。

**产品现实**：mean 89.36%（单次）/ max 90.38%（多 seed 取优），已超商业软件典型 82–88%，距人工 93% 差 ~3pp。多 seed 重启后可作为 90% 级产品。

> 口径说明：erode 是几何近似（腐蚀 = 允许重叠），实测的是"若允许该重合，利用率能到 X%"，即约束层预处理后的潜在收益上限；实际引擎须支持指定片对重叠 d mm（[阶段 1](#阶段-1erode--产品化合法性验证1--2-天最大风险--关键分叉点) 验证）。

## 七、风险与待确认

1. **erode 产品化合法性**（阶段 1）：最大风险，决定约束层轻还是重。**先验证再投入**，不直接写阶段 2。
2. **spyrrow 依赖**：0.9.0 < 1.0，API 会动（已踩过 `num_workers` 坑）。sparrow 本体是 Rust+WASM，spyrrow 是 Python 绑定。产品化 vendor + 锁版本，必要时 fork Python 绑定。
3. **sparrow 解的确定性**：anytime + 随机种子，同输入能否复现？产品要确定性输出，需测。
4. **0.4mm 外部公差**：sparrow 是矢量精确几何（不像位图 2mm），理论能表达 0.4mm——阶段 1 验证。

## 十、历史（v1 / B 路径 GLS 自研，已被 hybrid 取代）

> 保留作回退方案。若 hybrid 阶段 1 证明 erode 路径产品化不成立，回此方案。

### 10.1 v1 方案：B 路径（自研升级，不换底座）

原计划保留自研栈，把"位图FFT+弱SA"升级为"精确几何NFP + GLS引导"，学 sparrow 思想但不换底座。

**选 B 不选 A（换底座）的四个理由**（当时成立，现 hybrid 已部分借用 A）：
1. 所有开源引擎都不支持服装内外档重合 5–10mm，换底座 = 约束层推倒重来
2. 护城河（v0.3 规则 + 模板库 1b + GPU pipeline + DXF 解析）全在自研栈
3. sparrow 思想与"重合公差排料"同源，升级比替换自然
4. 工程量 B（2–3 月）< A（3–6 月），天花板相当
