# 创始共创伙伴合作协议要点（框架稿）

> **用途**：与织里裁床服务点 / 打版工作室洽谈创始共创合作时的条款要点清单，供双方沟通对齐与律师起草正式合同使用。
> **性质**：本文是商务框架稿，不是正式法律文件。签署版必须经执业律师审定。
> **版本**：v0.1（2026-09-16）｜配文：《织里商用推广可行性分析》（会话内）

---

## 0. 合作定位

| 项 | 约定 |
|---|---|
| 甲方 | 平台方（我方） |
| 乙方 | 创始共创伙伴（裁床服务点 / 打版工作室，个体工商户或公司均可签） |
| 性质 | 产品共创合作：乙方供给真实唛架与版师判定，甲方供给免费平台与对拍服务 |
| 非劳务 | 双方独立经营，不构成雇佣、合伙、代理关系 |
| 非独占 | 甲方不向乙方授予任何市场独占权；乙方不得主张排他（见 §7） |
| 名额 | 全镇创始伙伴 ≤3 家，按品类各 1 家（针织 / 童牛仔 / 羽绒），制造稀缺感但不构成独家 |

## 1. 创始期权益（乙方获得）

1. **免费使用期**：自签约起 12 个月，平台全部功能免费，不限张数。
2. **创始折扣**：创始期满且完成 §2 义务的，此后享标准定价 __ 折（建议 5 折）终身有效；未完成义务的按标准价。
3. **名分**：授予「创始共创伙伴」称号，乙方可用于自身对外宣传。
4. **优先服务**：旺季故障优先响应（SLA 建议：工作时段 ≤2h、其他时段 ≤8h，具体待谈）。
5. **对拍报告**：甲方每周向乙方交付其唛架的对拍报告（利用率差值、折算省料金额），报告内乙方数据乙方可自用。

## 2. 双方义务（交换物与量化口径）

**乙方每周供给（缺一即计入未达标）：**
1. 真实唛架 ≥ __ 张（建议 3~5 张，含面料成分、门幅、缩率、数量表等完整裁剪参数，唛架为乙方实际使用或客户送裁的版本）；
2. 版师判定时间 ≥1 小时（固定时段，对甲方排料结果逐项判定：可裁性、工艺合规、与人工方案对比结论）；
3. 及时报送上床结果：哪些甲方排的图实际上了裁床、有无裁剪异常。

**甲方每周交付：**
1. 对拍报告（同面料同门幅同数量，人工 vs 引擎，利用率 + 折算省料）；
2. 反馈闭环：乙方提出的问题 T+7 内书面答复（修复或排期）；
3. 版师判定时段的驻场 / 远程支持。

**达标机制**：连续 4 周唛架供给量低于约定值 50%，或连续 8 周版师判定时间不足 → 免费权益冻结，书面提醒后 4 周内未恢复则按未完成创始义务处理（影响 §1.2 折扣）。

## 3. 数据授权条款（清单）

**授权内容**：唛架与纸样文件（DXF/PLT）、面料参数、数量表、乙方现行排料结果、对拍数据。

**用途分级授权**：

| 级别 | 用途 | 默认状态 |
|---|---|---|
| L1 内部使用 | 算法改进、回归测试、对拍计算 | 授权（合作核心，不可谈判删除） |
| L2 脱敏对外 | 匿名案例、演示、行业报告（去除客户名、款号等可识别信息；对外仅用利用率等统计数字与整体截图，不外发完整唛架图） | 授权（可谈为逐次确认） |
| L3 商业转售 | 将乙方数据作为数据集出售 | **禁止**（明写，杜绝后患） |

**权属**：纸样、唛架及其内含款式的知识产权归乙方或其下游客户所有，甲方不主张任何所有权；本授权非独占、免费、仅限上表用途。

**下游客户权益**：唛架可能含乙方客户的款式，乙方保证就 L1（内部使用）有权授权；L2 对外展示的脱敏责任在甲方，乙方有权对单次展示提出异议并撤下。

**撤回机制**：
- L1 中的个体文件：乙方可随时书面要求删除，甲方 30 日内删除个体文件；
- 脱敏聚合统计（利用率、面积、时长等数字级数据）：建议谈判目标为不可撤回（已进入回归测试集的脱敏夹具同口径处理）；若乙方不接受，则撤回时同步删除并双方书面确认。

**安全措施**：传输加密、按伙伴隔离存储、访问人员最小化、合作终止后个体文件保留 ≤90 天即删除并出具删除确认。

## 4. 保密条款（清单）

**甲方对乙方保密**：客户名单、报价与计价方式、工艺偏好、唛架与纸样内容、对拍结果中乙方的商业数据。

**乙方对甲方保密**：算法与技术细节、产品规划、定价策略、未发布功能、共创沟通内容。

**期限**：合作期内 + 终止后 3 年（建议值）。

**例外**：签署时已公开的信息、独立合法获得的信息、法律法规或司法/监管机关要求披露（应提前通知对方）。

**违约救济**：约定违约金 __ 元/次，或按实际损失孰高（待律师建议）。

**互不挖角**（可选条款）：合作期内及终止后 1 年内，双方不主动招揽对方员工。

## 5. 责任边界与赔偿

1. **上床验收闸门**：乙方版师对排料图的验收是上裁床前的必经流程。**未经乙方版师验收直接上床造成的损失，甲方不承担责任**——此条同时是共创流程要求和责任分界线。
2. **赔偿范围**：仅赔直接损失（面料报废、返工的直接成本）；间接损失（断货、交期延误、商誉、利润损失）不赔。
3. **赔偿上限**：创始免费期内，单次事故赔偿 ≤ 该床面料成本的 __%（建议 50%）且全年累计 ≤ __ 万元；付费期另议（建议年费的 3 倍封顶）。**免费 ≠ 免责，但责任要对称于收费水平。**
4. **商业化后投保产品责任险**，将此风险转移到保险。
5. 唛架正确但裁床执行、拉布、面料自身疵点等非唛架原因造成的损失，甲方免责。

## 6. 知识产权归属

1. 平台（含算法、界面、报告生成器等）全部知识产权归甲方。
2. 乙方纸样、唛架知识产权归乙方（含其下游客户的权利）。
3. **乙方反馈不构成共有权**：乙方提出的排料规则、工艺要求、改进建议，甲方据此开发的功能归甲方单独所有，乙方不主张共有、署名权或分成——对价已体现在 §1 创始权益中。
4. 对拍报告整体版权归甲方；其中乙方数据部分乙方可自用宣传，甲方对外使用按 §3 L2 脱敏口径。

## 7. 使用范围限制

1. 平台账号仅限乙方内部及其客户订单服务使用，**不得转售、转租或以任何形式向第三方提供平台访问**（防止账号被当「二房东」转卖）。
2. 乙方不得以「独家」「唯一」等排他性表述对外宣传本合作。

## 8. 期限、终止与退出

1. 创始期 12 个月，期满自动转标准合作（按 §1.2 折扣）。
2. 任一方提前 30 天书面通知可无因终止。
3. 重大违约（数据转售、批量泄密、义务长期不达标经催告不改）可即时终止。
4. 终止后：个体数据按 §3 撤回机制处理；完成创始期义务的折扣保留；双方停止使用对方保密信息。

## 9. 争议解决

协商优先 → 协商不成提交湖州（吴兴区）有管辖权的人民法院 / 仲裁（二选一，待律师建议）。适用中华人民共和国法律。

## 附录 A：伙伴筛选清单（「只找生意好的人」的落地指标）

> 原则：人工排料自己也能出结果，所以只有「排不过来」的人才有真实痛感与真实反馈；生意平平的伙伴给的是礼貌性好评，会污染产品验证信号。

**入选硬指标（满足 ≥4 项）：**
- [ ] 经营 ≥3 年（穿越过周期）
- [ ] 裁床两班倒，或月裁剪 ≥30 床
- [ ] 版师 ≥2 人且旺季常态加班 / 排期排队（产能受限的直接证据）
- [ ] 已购拉布机 / 自动裁床 / 吊挂等设备（有「为效率付费」的历史）
- [ ] 稳定外发客户 ≥5 家（被市场反复验证）
- [ ] 旺季订单外溢需要外包（产能瓶颈外显）

**反向排除：**
- 生意平平但态度热络的「甜蜜陷阱」：有时间陪你聊、全是好评、但唛架量不足以产生统计意义、且永远不上床验证
- 刚扩产、机器等人的（产能富余 → 无痛感）
- 按裁剪米数计价且不愿改的（省料 = 他减收，利益根本对立，见附录 B）

**时机**：避开旺季峰值（双东备货期 9~10 月的头两周），选旺季中后段或平季签约——那时产能痛感还在、人还腾得出手。

## 附录 B：签署前摸底清单（决定话术与条款侧重）

- [ ] **计价模式**：按米 / 按床 / 按件？→ 按米计价的省料减收冲突需先解决（改话术为「帮你抢单」或放弃）
- [ ] **版师态度**：愿不愿做「裁判」而非「对手」？（引擎定位为放大版师产能，不替代）
- [ ] **主营品类**：与品类适配路线（针织 / 童牛仔 / 羽绒）对齐，每品类只签 1 家
- [ ] **历史唛架库**：有无近半年唛架存档可直接拿来做对拍冷启动（签约前就能出第一份报告敲门）
- [ ] **数据资产权属**：唛架多来自下游客户，乙方对 L1 内部使用的授权确认
- [ ] **老板决策链**：一人拍板还是夫妻 / 合伙人共决（影响签约周期）
