# 排料可视化工作台 · 导出功能 方案（v1）

> 状态：已评审确认，待实现　　日期：2026-08-08
> 关联：[[排料可视化工作台_实现计划.md]] · 排料工作台阶段 A/B/C（代码 `material sorting_web/`）

## 1. 背景与需求

排料工作台基本功能已完善（实时求解可视化 + 多 seed 并排对比回放 + 片 hover + 收敛曲线）。下一步增加**导出按钮**：

- 默认导出**当前利用率最高**的排料方案（`runs` 中 `finalDensity` 最大者；单 seed 即该 run 本身）。
- 两种格式：
  1. **PNG** —— 给用户直观查看、可打印存档、发微信给版师。
  2. **ASTM/AAMA-DXF marker** —— 给版师在 ET 里编辑/测量，乃至直接喂切割软件。

## 2. 三个关键决策（已与用户确认）

| 维度 | 决策 | 理由 |
|---|---|---|
| **裁片轮廓** | 真实尺寸（母版原始轮廓） | 尺寸准确、可直接裁剪；内部片显示 v0.3 允许的重合区（≤10mm），正好作为送版师审"重合合法性"的依据。eroded 版偏小不可裁剪，仅作排料求解中间量。 |
| **DXF 格式严格度** | 务实 R12（ET 直开） | 每片=闭合 POLYLINE + 门幅边框 + ASCII 标题，复用已验证 R12+POLYLINE 方案，规避 ET2008 LWPOLYLINE 轮廓消失坑。严格 ASTM D6648（BLOCK/INSERT+元数据）工作量大且当前无剪口/钻眼数据可填，列为后续。 |
| **PNG 内容** | 排料图 + 标题信息 | 干净排料布局 + 顶部标题（码号集合/利用率/用布长度/seed），直观可存档。 |

## 3. 交互与触发

- 左栏 `#stats` 下方新增「**导出最优方案**」区，两个按钮：`导出 PNG` / `导出 DXF`，求解完成前 `disabled`。
- 点击 → 自动取最优 run 的**最终帧** `lastFrame.placed_items` 作为排料结果。
- 无可导出（未求解 / 0 片）→ 状态提示，不报错。

## 4. 架构：导出统一在服务端做（PNG 也走服务端）

理由：
1. 要用**真实轮廓**，而真实轮廓只在服务端 `PIECES` 缓存（`pieces_intermediate.json`）里；前端 manifest 只有 eroded 版。
2. PNG/DXF 用同一份几何、同一套类型配色，保证两个文件画面一致。
3. `matplotlib` + `ezdxf` 可用；`cairosvg` 缺失且 Windows 有 native 库坑，弃用。

数据流：

```
前端 bestRun() → POST /export { fmt, sizes, seed, gate_mm, width_mm, density,
                                 placed:[{id,rotation,translation},...] }
后端  PIECES[pid] → 原始 polygon + ptype → 旋转平移到世界坐标 → PNG(matplotlib) / R12-DXF(ezdxf)
浏览器收到字节流 → 下载
```

## 5. 几何关键点（PNG/DXF 共用）

- **变换**：对原始轮廓顶点套 `R(θ)·(x,y)+(tx,ty)`，θ=`rotation`、(tx,ty)=`translation`（与前端 `lib/geometry.ts::pointsStr` 同公式；vanilla 前身已迁移）。
- **坐标系**：沿用 spyrrow 世界坐标 **X=用布长度(0..width)，Y=门幅(0..1980)，Y 向上**。
  - 与屏幕所见方向一致：前端 SVG 的 `translate(0 gate) scale(1 -1)` 翻转后即 Y 向上，PNG 直接对应屏幕观感。
- **轮廓=真实母版轮廓**放到 erode 后的变换位：外部片相切/≤4mm 重合，内部片显示 v0.3 允许重合区（≤10mm）。
- **类型配色**：复用 `sparrow_baseline.PTYPE_COLORS`（前端已在用），PNG 与屏幕同色。

> 说明：PNG 仍用 eroded 几何会与 DXF（真实）不一致；选真实轮廓后两者一致，故 PNG 也必须在服务端用原始轮廓渲染。

## 6. PNG 渲染（matplotlib）

- 画布按 marker 真实长宽比，最长边封顶 ~3000px 防过大。
- 门幅矩形（浅底 + 虚线边）+ 每片 `Polygon(facecolor=类型色, alpha=0.55, edgecolor=类型色)`。
- 顶部标题：`M1787 直筒 | 码 28–36 | 利用率 87.99% | 用布 X.XX m | 门幅 1980mm | seed 0`。
- 等比、隐藏坐标轴、左下原点；附一个紧凑类型图例。
- `savefig(dpi=…, bbox_inches='tight', facecolor='#eef0f3')` → PNG 字节流返回。

## 7. DXF marker（ezdxf R12，复刻 `nesting_bounds/export.py` 已验证套路）

- `ezdxf.new('R12')` + `$MEASUREMENT=1`（metric，mm 隐式）+ 抑制 ezdxf R12 `$INSUNITS` 警告。
- 门幅边框 `[(0,0),(W,0),(W,gate),(0,gate),(0,0)]` color 7。
- 每片 = 闭合 `POLYLINE`（`add_polyline2d`，首尾闭合），按类型 ACI 上色，全放 layer 0。
  - **坚决不用 LWPOLYLINE**（ET2008 轮廓消失老坑，见 ET DXF 教训）。
- ASCII 标题 TEXT：`M1787 util=87.99% L=XXXcm gate=1980 seed=0`（ASCII 避编码问题）。
- 写临时文件再读字节返回（ezdxf `saveas` 走路径最稳）。

## 9. 边界与校验

- 未求解 / 0 片 → 按钮禁用或提示，不崩。
- `pid` 查不到 → 跳过并记日志（正常不应发生）。
- 多 seed：按 `finalDensity` 取最大，并列取首个。
- 文件名：中文走 RFC5987 `filename*=UTF-8''…`，同时给 ASCII fallback，避免乱码。
- **验证清单**：
  1. 单码短求解后导出 PNG，目检与屏幕布局一致、标题正确。
  2. 导出 DXF 后用 ezdxf 回读校验：片数==placed 数、边框存在、坐标全在 `[0,W]×[0,gate]`。
  3. 多 seed 导出，确认标题里是 best seed 的利用率。
  4. ET 实开由用户/版师手动确认。

## 10. 暂不做（后续）

- 布纹线 / 剪口 / 钻眼（`pieces_intermediate.json` 无此元数据，需回母版 DXF 补）。
- 严格 ASTM D6648（BLOCK/INSERT + 片元数据实体），待明确目标切割软件型号再做。
- eroded 轮廓导出开关（可后续加复选框）。
- 分床 / cut-order / 多 marker 切分。
