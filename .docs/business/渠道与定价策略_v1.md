# 渠道与定价策略 v1

> 定案日期：2026-10-08 · 状态：v1 定案执行（§6 加盟段为备档，暂缓）
> 适用：个体户版师客群 · 本地部署（exe + keyserver 时长 key）· 牛仔产业集群市场
> 核心结构：**推广主力 = 散推网络（一次性现金奖励）；唯一合作版师 = 收口与管理者（非销量引擎）**

- **在期续费 = 天数叠加顺延**，不做"在期禁买"（版师手头有钱时才买得起卡）。

- **涨价纪律**：只涨新客、不动存量。

## 2. 推广体系：两层在跑，一层备档

| 层 | 是谁 | 定位 | 拿什么 | 状态 |
|---|---|---|---|---|
| 散推网络 | 任意付费用户 | **推广主力**——一次性现金奖励驱动的无边界增量引擎 | 首单佣金 ¥30/100/400 + 被推者 +15天 | 立即执行 |
| 种子合伙人 | 唯一合作版师 ×1 | **收口与管理者**——信任背书 / 一线支持 / 反馈收口 / 本地秩序 | 归属客户流水 30% 终身随续费 | 线下行招募 |
| 区域加盟 | 工作室/设备商 | 长尾覆盖机制（非利润主体） | 见 §6 备档 | **暂缓** |

### 量的来源（判断框架：量停滞时查散推激励与产品，不是加签版师）

1. **散推网络（主力）**：他带来的客户 + 直营客户人人可推，散推者之间无 Territory 无名分，天然不吵架；
2. **产品自传播**：每张交付唛架带信息表格（方案名/利用率/每套用料），91% 利用率数字在集群里自己说话；备注列放联系方式为可选开关；
3. **直营**：早鸟价渠道，线下亲跑；
4. **合伙人直推**：其半径 = 同行版师 5–15 人 + 服务厂 10–30 家，首季现实产出 10–25 个付费账号。

**期望管理**：单集群 6 个月做到 30–60 活跃账号（≈¥1–2 万/季流水、合伙人 ¥3–6k/季）即成功。

## 3. 散推网络规则（对外）

- 佣金：被推荐人**首单**成交后，推荐人得 月卡 ¥30 / 季卡 ¥100 / 年卡 ¥400，48 小时内微信红包（快发是口碑）；
- 双向奖励：被推荐人任意档 **+15 天**（成本为零，熟人推荐的润滑剂——朋友能落到实惠，推荐才张得开口）；
- 归属：以**新客户付款时报名为准，报了不能改**（客户说了算 = 终结 90% 渠道扯皮）；
- 限制：只奖首单不奖续费；推荐人 ≠ 付款人（规则写明、抽查执行，不上防伪系统）；
- 错卖防护（备而不用）：若出现诱导熟人重仓年卡引发投诉，年卡佣金改"¥200 即时 + ¥200 于 90 天后无退款投诉发放"。

## 4. 种子合伙人（收口与管理者）

### 4.1 角色定位

他**不是销量引擎**。四个职能：

1. **信任背书**——本地有声望的版师在用，就是最有力的广告；
2. **一线支持**——归属客户的使用问题第一响应人；
3. **反馈收口**——集群内问题与需求经他整理直达你（专属通道 + 新版内测资格，身份激励不比钱弱）;
4. **秩序管理**——本地规则解释、群里带节奏、防抢功。

**KPI 看收口质量不看量：归属客户续费率**（30% 终身随续费，经济上自动对齐）。

### 4.2 权责边界

| 他做 | 你保留（永不放） |
|---|---|
| 拉新（自己的客户圈） | 定价权 |
| 归属客户一线响应（工作时段 ≤2h） | key 发放 |
| 反馈收集整理（专属通道） | 总客服群（你建，他当副管理） |
| 本地秩序与规则解释 | 厂端客户（machine API 线）100% 直营 |

支持范围说明：一线支持**责任范围 = 他的归属客户**；总群内其他客户的问题他自愿答——人情题攒声望，声望即他的获客引擎；你兜全量保底。此边界写进协议，免得他觉得在给别人的客户免费打工。

### 4.3 分成与结算

- 归属客户流水 **30%，终身、随续费流动**，月结微信转账；
- **只算归属客户**（已否决"全量 30%"：多合伙人数学爆炸 / 白吃自营与厂端收入 / 搭便车 / 收入与努力脱钩）；
- 客户的朋友推荐归朋友（散推档），不归合伙人——**单层结构，永不两级分销**；
- 收款一律**直付你的收款码**（绝不许合伙人代收截留——价格体系会失控）；客户资产沉淀在你手，他是渠道不是墙。

### 4.4 选人标准（线下行用）

优先级：**信任半径**（同行有难题都找他、群里说话有人听）> **经营触点**（2–5 人工作室主 / 有设备商、培训机构人脉）> **软件不抵触**（日常用 ET/博克、会导 DXF）> **打版为主业**（代排附带，无"工具砸饭碗"焦虑）。排料手艺不在前三——他当的是节点，不是冠军。

### 4.5 招募流程

线下**不当场签**：送 7 天试用 → 以散推身份先推 2 单 → **2 周观察**（主动推了几人 / 反馈提得有无干货）→ 达标再谈合伙人一页纸（亲测替代"3 单门槛"，规则一致性无伤）。

### 4.6 给与不给

- **给**：自用终身 key（成本 0）、本集群 **12 个月独家**、"创始合伙人"名分、需求优先听；
- **不给**：更高分成。30% 是全体合伙人的常数——给第一个开口子，第二个集群合伙人出现那天就是你最难堪的一天。

### 4.7 退出与沉寂

- 已归属客户分成**终身照付**（不因沉寂停付，避免追讨纠纷与恶名）；
- 连续 6 个月零新增 → 独家自然失效（可引入新合伙人，已归属客户不动）——降级不踢人。

## 5. 三铁律与扩张规则（冲突预防）

**三铁律**：

1. **价格唯一**——任何人、任何渠道一个价，永不个案折扣（客户无从比较生怨；早鸟直营为例外期内唯一差价）；
2. **归属报名制**——新客户付款报名为准、报了不改（无抢功空间）；
3. **数据不出本机**——母版 DXF / 唛架 / 利用率全部留在客户电脑，服务端只做 key 验证。这是本地部署架构的真话，招募谈判时**比 30% 更有说服力**：版师最怕的是看家母版外泄让自己可替代。

**扩张规则**（未来多合伙人时）：

- 只开**新集群**（新塘/均安等地域人际天然隔离）；同集群加人须现有合伙人**提名背书**（功劳归他，嫉妒消解）；
- **永不公布合伙人业绩排名**（零和感是比较出来的，不是收入差出来的）;
- 一客户一归属，佣金只从一层出。

## 6. 加盟模式（备档，暂缓执行）

**缓的理由**：无留存数据 / 支持负荷未知 / 无可展示的合伙人赚钱案例——空降收加盟费，三月后加盟商赚不到钱，退费 + 集群口碑反噬致命。

**启动信号**：≥3 个合作版师连续两季度分成 ≥¥2,000（= 单 territory 年化 ¥2.7 万+ 流水被验证）。届时手里有真案例，加盟费才收得理直气壮；第一批候选 = 达标合伙人。

**若启动的结构（备档）**：

- 模式 = **预充值底价拿货**：加盟商预充值（如 ¥5,000 起），每发一张 key 按零售价 2 折扣余额（月 ¥29.8 / 季 ¥59.8 / 年 ¥256）。三合一：现金流先到 + 统一零售价控价（可向上捆绑自有培训/代排服务加价、禁止向下破价）+ **keyserver 即计量层**（所有 key 过你的服务器验证，瞒报收入在架构上不可能——这是比传统软件商安全的天然优势，谈判时可亮出来）；
- 加盟费 ¥1.28–1.98 万，含首批零售额度 ¥1 万；**首年保底流水 ¥2–3 万**，未达降级为非独家合伙人（不踢人）；回本账给候选人看：80% 毛利下流水约 ¥2.5 万回本（≈85 张季卡，月均 7 张）；
- 独家按**产业集群（镇级）**划，不按省；加盟商可在辖区内自建散推网络（奖金从其 80% 出，总部不重复贴）；
- **法律红线：合同用《区域独家授权经销协议》名义，不用"加盟/特许经营"**——《商业特许经营管理条例》要求两店一年 + 商务备案，现阶段不满足；卖软件授权、不授权品牌经营模式 = 普通经销，完全绕开；
- 认清定位：20% 收入背 100% 研发，加盟是**长尾覆盖机制不是利润主体**；利润锚点 = 直营 + 厂端 API（永不放加盟）。

## 7. 结算与运营配套

- **收款**：全部直付（微信/支付宝个人码起步，降低 friction）；月结对账；
- **keyserver 实现需求清单**（后续开发对齐本策略）：key 加"渠道归属"字段、试用 key（7 天/激活起算）、天数叠加、（远期）合伙人查询视图、（加盟期）预充值余额；
- **换机解绑**：每年免费解绑 2 次（版师换电脑是真实场景，客诉集中点）；
- **静默流失召回**：key 在期但 7 天未 validate → 微信主动问一句（授权列表"最新使用时间"列即召回雷达，续费率最大杠杆）；
- **结算合规**：小规模阶段微信转红包/转账为常态；上量后走个体户代开票或灵活用工平台。

## 8. 随身一页纸（打印版）

**对外 · 推荐规则**（给所有用户看）

> 推荐好友，好友首单成交后你得现金：**月卡 ¥30 / 季卡 ¥100 / 年卡 ¥400**（48 小时内微信红包）
> 好友立得 **+15 天**（任意档）
> 归属 = 好友付款时报你的名字，**报了不改**
> 只奖首单；推荐人不能是付款人

**对内 · 创始合伙人要点**（协议骨架）

> 分成：归属客户流水 **30%**，随续费**终身**，月结
> 职责：拉新 + 归属客户一线响应（工作时段 2 小时）+ 反馈收口（专属通道）
> 权利：自用终身 key、本集群 12 个月独家、创始合伙人名分、需求优先
> 保留：定价权 / key 发放 / 总客服群 / 厂端客户，永远归平台
> 数据：母版唛架不出客户本机，平台只做 key 验证
> 退出：已归属客户照付终身；连续 6 个月零新增独家失效
