## 2. 核心架构事实（可行性的出发点）

- spyrrow `Item` 仅 id/shape/demand/allowed_orientations（`.venv/.../spyrrow/__init__.pyi` 核实），**无固定片/障碍/初始解概念**，且 CLAUDE.md 约定「sparrow 不改源码」⇒ 「钉死 x=0」**不能作为求解约束**。
- P3 答复要求填充片与前缀凹口**跨界连续** ⇒ 前缀不能以障碍/硬缝形式存在于求解之外。
- 两者唯一同时满足的形态：**前缀以组合片身份自由进解（跨界填充由求解器 NFP 邻接原生完成，band FR-9 同机制、+2.27pt 实证），解后用纯几何变换把组合片钉到 x=0（钉位不进求解）**。

## 3. 机制设计：组合片 + 段置换钉位 + 驱逐重插

### 3.1 前缀组合片构造（`PS_*`，复用 band 第 3~5 步管线）

1. 4 片按版师形态构造性贴触：竖排、相邻 180° 交替、`_slide_touch` 贴触（无 RNG）；y 向钳 ≤ `PLOT_SAFE_MAX_Y_MM`。
2. 原始轮廓 union → erode(d_g)（前/后幅外部展示级 d）→ 归一化到原点；`PS_` 前缀哨兵，永不出 manifest/frame/导出（US-011 纪律）。
3. orientations **锁 [0.]**（形态有方向性；band 允许 180 是因整带头尾调换版师已确认，此处默认锁死——残余确认项③）。
4. 主实例扣减：exclude **pid 级** `{(front,S), (back,S)}`（现 `solver.py` exclude_labels 为 label 级，需扩展；2+2 恰用尽该码前后幅 demand；pid_meta/total_area/manifest 原样）。

### 3.2 主求解

`PS_*` 组合片作为普通自由 Item 进解（与 `WB_*` 同模式，可同开）；其余裁片正常。跨界填充 = 求解器对 union 外轮廓凹口的 NFP 邻接，天然支持「填充片同时占前缀凹口与外部空间」——**这正是 P3 要求的字面实现**。

### 3.3 解后段置换钉位（密度零损失的钉位）

设最终解中组合片 x 占据 [a, b]，取割线 c1=a（硬性，保证贴零）、c2≥b（邻域柔性选线，最小化驱逐片数），把全版裁片按 x 区间三分组：

- **A 组**：x-span ⊆ [a, c2]（组合片 + 深窝填充片）→ 整体平移到 x=0，**嵌套关系原样保留**；
- **C 组**：max_x ≤ a（组合片左侧片）、**B 组**：min_x ≥ c2（右侧片）→ 依 A、C、B 顺序拼接（各组刚体平移）；
- **总长不增**：`new_L = (c2−a) + span(C) + span(B) ≤ L`（组间 x 区间不相交由构造保证，**无新重叠可能**；刚体平移不改任何片朝向/布纹）；
- **band 同开（P4）**：同机制再加两条割线把 `WB_*` 段置换到布尾；组合片求解落位已在 x≈0 则跳过置换（零代价）。

### 3.4 驱逐重插（唯一密度代价）

- 驱逐片 = 跨越任一割线的「浅窝跨界填充片」（straddler，预估每割线 3~6 片小件）。
- 重插优先序：① **原窝回位**（随 A 组平移量平移后 +x 推入原凹口，凹口空间随组合片平移仍在，多数情况下零代价）；② 全版自由空间贪心贴触插入（复用 US-015 `_fill_gaps`：候选锚棱 × rot{0,180} × 双滑向 + 二分，代价 = bbox 增长最小）；③ 尾端贴触追加兜底（总长增长，计入密度差上报，守卫阈值 warn）。
- 终检：`constraints.validate` 全版复检 + y≤1910 复检，失败回退置换前布局（LNS 纪律：交付物恒过检）。

### 3.5 帧发射与确定性

置换+重插挂在 `solve_worker._emit_placed` 后（final 单点，band 展开同一挂点）；帧内廉价版（置换 + 驱逐片尾端刚体追加）保证第 1 帧起前缀就在 x=0。全程确定性几何（无 RNG），多 seed 逐 seed 置换，portfolio/kill/ETT 语义不变。

## 4. 密度代价与接受线

| 项 | 代价 |
|---|---|
| 段置换本身 | **0**（总长不增，纯刚体平移重排，无新重叠） |
| 驱逐重插 | **0.2~0.8pt**（原窝回位多数零代价；贪心贴触次之；尾部追加才真增长） |
| 组合片 vs 自由 4 片 | 与 band 同构（求解器对 union 外轮廓 NFP 邻接回收，band 实测为正贡献） |
| 对比：纯拼接式（已被 P3 否决） | 0.5~1.9pt（bbox 硬缝 + 前缀区独立构造） |

接受线 ≤1.0pt（band「不显著劣化」哲学）；P0 探针实测定案，超标回设计台（主要调形态/交错顺序）。

## 5. 风险与边界

1. **封闭内腔死区**：4 片 union 的封闭腔 spyrrow 无洞支持（band 肋间同题）——版师形态为边缘开口楔缝，构造时保持缺口单侧开放即可规避。
2. **驱逐片尾部追加失控**：守卫 = 追加总宽超阈值 warn + 密度差如实上报。
3. **组合片 180°**：默认锁 0°；若版师认可形态 180° 对称可放开（放宽求解邻接）。
4. **LNS 互斥**：prefix on 时 `--lns` warn 跳过（波段重排拆钉位），同 band 现状；二期 frozen 片概念（PC-007 欠账）。
5. **多 seed/策略**：逐 seed 置换（确定性几何），`--strategy`/kill/target 全兼容；P4 带尾置换在同链路完成。

## 7. P0 探针实测结果（2026-08-25，5336 真实数据；探针脚本 `out/tmp_probe/probe{1,2,3}_*.py` + `prefix_lib.py`，可复跑）

**① 资格码表**：前/后幅 = **g02 / g03**（1153×484 / 1155×360 两大片，几何判定）；资格码（front demand==2 且 back demand==2）= **{32, 33, 34, 35, 38}**；31（1+1）与 36（3+3）不合格——与版师「2 片或 6 片的码不行」逐字吻合。

**② 组合片直测**（size 34 + min/max 资格码 32/38 同构，d_g=2mm，gate_nest=1910）：

| 变体 | bbox | fill | 贴触缝隙 | 封闭腔 |
|---|---|---|---|---|
| **interleave（前后前后）** | 1155×1458 | 83.3% | 全 0.00mm | **0**（缺口全开放） |
| grouped（前前前后） | 同量级 | 略低 | 0.00mm | 2（= spyrrow 死区） |

→ interleave 优：0 封闭腔意味着跨界填充无暗坑；竖排高 1458 ≤ 1910 幅宽安全。两变体 SVG 已拷入 `.docs/business/`（残余确认项①勾选用）。

**③ 三臂 A/B**（60s × seed{0,1,2,3}，raw-width 口径 = total_area/(raw_width×min(gate,1910))，与 90% 生死线同分母）：

| seed | OFF | FREE (Δ) | PIN (Δ) |
|---|---|---|---|
| 0 | 86.84 | **88.61 (+1.77)** | 88.61 (+1.77) |
| 1 | 86.28 | 86.07 (−0.21) | 86.07 (−0.21) |
| 2 | 88.16 | 86.28 (−1.88) | 86.28 (−1.88) |
| 3 | 86.38 | 86.16 (−0.22) | 86.16 (−0.22) |
| **均值** | **86.92** | **86.78 (−0.14)** | **86.78 (−0.14)** |

- **均值代价 −0.14pt ≈ 零**（预估 0.2~0.8pt，实测更好；远过 ≤1.0pt 接受线）。逐 seed 波动 +1.77/−1.88 与 OFF 自身 seed 散布（86.28~88.16，1.88pt）同量级，属求解噪声而非机制代价。
- **PIN ≡ FREE，4/4 全部置换跳过**（`skip_at_head` 守卫生效）：大组合片在 sparrow 求解中自然锚定布头（comp_min_x 0.0~0.2mm）——「组合片自由进解」即常态路径，置换+驱逐重插整套机制为零成本兜底（仅异常解时触发），生产实现按 FREE 常态 + PIN 守卫双层结构落地。

**④ band×prefix 双开冒烟**（60s × seed{0,1}，WB_g05 全码带 + PS_g02+g03@34）：**89.33% / 90.05%**——全部实验最高值（≥ band 单开历史 88.35%）；PS 头部锚定不受 WB 干扰（min_x 0.0/0.1mm）。**P4 缺口**：WB 自由解落位在 PS 右侧紧邻（min_x≈1150，距布尾 ~5.2m），不满足「带靠最右」→ 带尾置换（§3.3 四割线版）未接线，进 PRD US-002（残余项④）。另观测 WB_rot=−180（FR-8 已知边界：整带开口朝右，band 生产链路同款行为，非 prefix 引入）。

**⑤ 判定：过线，可 /prd 立项**。密度代价 −0.14pt ≈ 0（③）、双开与 band 正交且达 90%+（④）、机制三层「自由进解（常态锚定）→ 段置换（兜底）→ 驱逐重插（兜底的兜底）」全链路已在探针验证。进 Ralph 循环：US-001 prefix 组合片+置换核心模块 → US-002 编排接线（含带尾置换四割线）→ US-003 UI（资格码下拉）→ US-004 A/B 验收；LNS frozen 留二期。
