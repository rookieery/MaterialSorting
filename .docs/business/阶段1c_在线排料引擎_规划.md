## 3. 关键设计决策

### 3.1 "块"的表示 —— 位图，不算精确多边形布尔

块 = A 片在 (0,0) + B 片在模板 offset (dx,dy)。块的几何 = A∪B。
- **不算精确多边形并集**（需 shapely，没装且复杂）。
- **用位图 OR 表示块**：块位图 = A 位图 ∨ 平移后的 B 位图。位图直接用于排块碰撞。
- 导出时再算每片世界坐标（A 在块位置、B 在块位置+offset），精确。
- 💡 这是位图化路线的延续：块、片、碰撞全程位图，避免精确多边形布尔。

### 3.2 排块算法 —— 候选点 BLF + 位图碰撞（非 FFT）

阶段 0 的 BLF（候选点 + 多边形碰撞）失败在"大裁片单列竖排"。但那是因为**单片**几何 + 候选点策略。
1c 排的是**块**（已嵌套，形状紧凑），且用位图碰撞（精确）。算法：

- 候选位置 = 已放块 bbox 四角 + 已放块位图顶点（参考 1b 的多边形顶点候选）
- 每候选：块位图平移到候选，与"已放累积位图"做 AND → 碰撞判定（位图像素重叠）
- 选最低最左合法位置（BLF）
- 💡 不用 FFT（FFT 适合"两片嵌套找最优 offset"，多片累积排料用候选点+AND 更直接）

### 3.3 组块策略 —— 同码内按模板贪心，跨码不组块

- 模板是基准码 28 算的，**只在同码内组块**（如 28 码后片+28 码前片），用归一化 offset × 该码 A 尺寸恢复实际 offset。
- 跨码形状不同，组块会引入误差 → 跨码优势靠**套排**（不同码的块/片在同一张排料图互补），不靠跨码组块。
- 组块顺序按模板价值（核心大裁片对优先，占面积大的先组）。
- 镜像：成对类 L/R，模板对 L 算，R 用镜像 offset（对称，免费）。
- 未能组块的片作单片段排料。

### 3.4 SA 优化 —— 搜"组块分配 + 顺序"，GPU 并行多链

- 状态：{组块分配（哪些片配成块）、块与单片段的排料顺序}
- 邻域：①换一组配对 ②交换两块顺序 ③把单片段改插别处
- 评估：跑一次排块算利用率（串行，~秒级）
- GPU 并行：多链 SA（如 16 链），每链独立排块，batch 评估。4080S 扛得住。
- anytime：记录全局最优，超时返回当前最优。

## 6. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 组块后块太大，门幅内排不开 | 块宽监控；超门幅的块拆回单片 |
| 位图碰撞在大画布（1980×7000mm）慢 | RES=2 起步；碰撞用 bbox 预筛 + 局部位图 AND |
| SA 评估慢（每候选=一次排块）| 先单链验证有效，再上多链 GPU；anytime 保底 |
| 跨码模板误差（大码形状变）| 关键码各算模板（1b 已留归一化接口）；误差超阈值的码重算 |
| 块的复杂形状导致排块缝隙多 | SA + 单片段填缝（小裁片塞块间缝隙）|
