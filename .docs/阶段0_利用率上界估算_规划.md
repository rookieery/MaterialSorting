# 阶段 0：利用率上界估算器 —— 代码规划

> **定位**：整体路线图（[docs/排料引擎技术分析.md](../docs/排料引擎技术分析.md) §5）的第一步。
> 目标是用最小工程量回答：**M1787 直筒款（8 套）的利用率物理天花板在哪？95% 到底行不行？**
>
> **状态**：✅ 已确认（v2）。补充输出要求：排料后 **DXF** + **SVG（标注利用率）**。

---

## 1. 数据现状（已确认）

**输入数据**：`material sorting/data/m1787_直筒/{类型}_{码号}.dxf`，文件名直接编码语义。

- 每个 DXF = 1 条 layer1 **毛版**闭合 POLYLINE（外缝线，含缝份）+ 1 条 layer7 布纹线 LINE
- **单片/文件**：成对类（前片/后片/腰/前袋/后袋/机头）每文件 1 片，排料时**镜像展开**为成对的另一片
- **单文件=单片、成对镜像展开、用毛版** —— 已确认

**用户需求**（[用户需求.md](用户需求.md)）：8 套 = 28+29+30+31+33+34+35+36（跳过 32）

**8 套总面积 = 12.55 m²**。门幅 1980mm 下的基准：

| 目标利用率 | 需用布长度 | 缝隙预算 |
|---|---|---|
| 100%（理论极限） | 634 cm | 0 |
| **95%** | **667 cm** | **33 cm（5%）** |
| 93%（厂家要求） | 682 cm | 48 cm（6.7%）|
| 90% | 704 cm | 70 cm（10%）|

→ 95% 缝隙预算仅 5%，非常激进。前/后片占单套面积 72%，裆弯互补咬合是决定天花板的关键。

---

## 2. 目标与成功标准

**产出**：该款型的"利用率天花板估算"区间 + 95% 可行性判断 + 可预览的排料图。

**成功标准**：
1. 给出**乐观上界**（理论面积法）与**悲观下界**（贪心排料法），真实天花板落在其间。
2. 给出 **95% 可行性的明确判断**（可达 / 临界 / 不可达），附数据依据。
3. 输出**排料后 DXF + SVG**（SVG 标注利用率），可预览校验。
4. 纯 Python + numpy，不引入新依赖。

---

## 3. 方法设计（三层）

### L1：理论面积分析（必做）
Σ面积、理论最小 L、各片面积占比、大裁片门幅几何可行性（前/后片 bbox 宽 ~1020mm，门幅 1980mm 单行放不下两片并排）。→ 乐观上界。

### L2a：矩形包络 BLF 贪心排料（必做，最悲观下界）
每片用 bbox 矩形，面积降序，BLF 放入 1980mm 宽无限长条带。允许 0°/180°。→ 悲观下界。

### L2b：多边形 BLF 贪心排料（确认做，更紧下界）
实际多边形碰撞检测（bbox 预筛 + 顶点测试 + 边相交），候选点用已放片 bbox 角点。顶点过多时抽稀。→ 收紧下界。

**最终结论**：真实天花板 ∈ [L2b, L1 修正上界]。

## 5. 关键技术决策（已确认）

| 决策点 | 选择 | 理由 |
|---|---|---|
| 依赖 | 纯 Python + numpy + 自写 SVG | 轻量、即跑即得 |
| 约束强度 | **最宽松**：不强制布纹线/镜像配对/重合，允许 0°/180° | 估"物理天花板"用最宽松约束 |
| 成对处理 | 成对类展开为 L+R 两片，独立排 | 镜像约束只降不升利用率 |
| 排料算法 | BLF 贪心（面积降序）+ 0°/180° | 阶段0 求 ballpark |
| L2b 多边形排料 | **做** | 收紧下界，让区间有意义 |
| DXF 版本 | R12 + POLYLINE | 兼容 ET（避免 LWPOLYLINE 轮廓消失的老坑） |

## 6. 输出物（已确认）

1. `report.md`：结论先行 ——「天花板 X%~Y%，95% 可达/临界/不可达」+ 依据
2. `report.json`：各片面积、各码面积、L1/L2 明细
3. **排料结果 DXF**（`nest_rect.dxf` / `nest_poly.dxf`）：每片按排料位置平移+旋转后的几何，R12 POLYLINE，可导入 ET/切割校验
4. **排料结果 SVG**（`nest_rect.svg` / `nest_poly.svg`）：人读预览，每片按类型着色+码号标注，**标题标注利用率/用布长度**
5. `area_analysis.svg`：面积占比 + 尺寸分布
