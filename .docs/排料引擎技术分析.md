# 排料引擎技术分析

> **文档目的**：基于玉林版师确认的排料规则，回答两个核心优化方向的可行性——
> - **方向 A**：同样的利用率，程序能否用更少时间（人工 20min → 程序 2min）
> - **方向 B**：不考虑时间，能否在当前场景把利用率提得更高（93% → 95%）
>
> 并给出统一的引擎架构与落地路径。
>
> **输入依赖**：[排料规则_详细版.md](../material%20sorting/排料规则_详细版.md)（v0.3，约束 spec）
> **创建日期**：2026-08-05
> **状态**：方向已确立，待启动阶段 0

---

## 1. 问题定义与规模量化

### 1.1 问题本质

牛仔裤排料 = **带领域约束的二维不规则条带排样（2D Irregular Strip Packing，NP-hard）**：
固定门幅（1980mm），最小化用布长度 L，等价于最大化利用率：

```
利用率 = Σ裁片面积(含缝份) / (1980mm × L)
```

所有约束来自 [排料规则_详细版.md](../material%20sorting/排料规则_详细版.md) v0.3，要点：
- 布纹线水平（硬）；合法姿态 = `{0°, 180°} × 各片小公差`
- 外部展示裁片：旋转 ≤±3°、重合 0.4~2mm
- 内部裁片：旋转 ±8~45°、重合 5~10mm
- 成对镜像（前片/后片/腰/前袋/后袋/机头/短双排）
- 多码套排，约 8 套

### 1.2 问题规模

| 项 | 值 |
|---|---|
| 单套裁片 | ≈ 18 片（7 成对类 ×2 + 单排/双排/火机袋/裤耳） |
| 套排规模 | ≈ 8 套 |
| **一次排料总片数** | **≈ 144 片**（其中 8 根裤耳为长条） |

**这是中大规模排料**。参照：SVGNest / DeepNest 公开 demo 通常几十片，144 片已是工业级。

### 1.3 搜索空间分析（可行性判断的基础）

| 维度 | 玉林场景 | 通用排料（CNC/激光） | 压缩比 |
|---|---|---|---|
| 旋转 | `{0°,180°}` × 小公差（外部 ±1°，内部最大 ±45°） | 任意 0–360° | **小 1–2 个数量级** |
| 方向 | 布纹线硬约束砍掉 ±90° | 自由 | 减半再减半 |
| 翻转 | 成对镜像预处理消除 | 自由变量 | 离散消除 |

**关键判断**：玉林的硬约束**不是让排料更难，而是把搜索空间砍小了 1–2 个数量级**。这是程序相对人工有速度优势的根本原因——人工其实也在这个受限空间里搜，只是人慢、靠直觉。

## 2. 两个优化方向的可行性

### 2.1 方向 A（同利用率，更快：20min → 2min）—— 可行性：**高**

**为什么 10× 加速现实可行：**

1. **NFP + BLF 放置是确定性、毫秒级的**。给定"片序 + 每片姿态"，BLF（Bottom-Left-Fill）在 NFP（No-Fit Polygon）边缘找最低最左切点，是 O(n) 几何运算。慢的不是"放下"，是"搜好的片序 × 姿态组合"。
2. **搜索空间被砍小**（§1.3），启发式更易命中好解。
3. **版师经验 = 高质量初始解（最大杠杆）**。把 v0.3 规则 + 版师隐性 know-how 编码成"构造启发式"，算法第 0 秒就能给出 85–88% 的合法解；局部搜索在此基础上挤到 93%，比从随机起步省一个数量级时间。
4. **多核并行**（SA 多起点 / GA 种群），10× 是常规操作。

**2 分钟预算分解：**

| 阶段 | 耗时 | 说明 |
|---|---|---|
| NFP 预计算（144 片两两） | ~5–15s | 大头，但**可缓存**（同款型只算一次） |
| 启发式构造初始解 | ~1s | 版师规则编码 |
| 多起点 SA（8–16 核） | ~90s | 主搜索 |
| 输出 + SVG 渲染 | ~5s | |

**主要风险（决定能否稳定到 93%）：版师经验编码的完整度。**
- 只靠通用 SA：2 分钟可能 88–90%
- 加领域启发式初始解（大片优先、成对配对、套排码互补、机头贴后片轮廓、内部裁片塞缝隙、`{0°,180°}` 头尾咬合）：到 93% 现实

→ 启发式规则就是产品壁垒，开源引擎给不了。

**商业价值**：降本（替代 20min 人工）+ 经验可复制（不依赖老版师）+ 数字化可追溯。**这是最该先做的 MVP。**

### 2.2 方向 B（更长时间，更高利用率：93% → 95%）—— 可行性：**有条件**

#### 2.2.1 必须先建立"利用率物理上界"概念

**95% 不是想达到就能达到的。** 利用率有天花板，由「1980mm 门幅 × 裁片几何 × 硬约束」共同决定：

- **几何不可咬合**：裆弯、腰弧是复杂曲线，两片间总有凹凸缝隙填不满。前/后片裆弯是最大的"不可压缩区"。
- **硬约束锁死大裁片**：前/后片 ±1°、重合仅 2mm——这两块最大的裁片几乎不能动，它们之间的缝隙无法靠旋转消除。
- **门幅边界锯齿浪费**：1980mm 边缘总有切边余料。
- **布纹线约束**：所有片水平，无法倾斜填斜缝。

**不同款型天花板差异巨大**（版师说"和版型有关系"的真相）：
- 紧身窄脚款（裁片细长、裆弯缓和）：可能 94–95%
- 阔腿宽松款（裁片宽大、裆弯复杂）：天花板可能就 92–93%

→ **方向 B 的第一个交付物不该是"95% 排料器"，而是"利用率上界估算器"**：拿现有 M1787 母版跑长时段无约束近似排料，得出各款型经验上界。先搞清天花板，再决定值不值得追。

#### 2.2.2 方向 B 的真实杠杆（按收益排序，全部来自 v0.3 规则）

| 排名 | 杠杆 | 收益 | 依据 |
|---|---|---|---|
| 1 | **`{0°,180°}` 双姿态充分搜索** | 大 | v0.3 §3.1；前后片头尾相对 180° 让裆弯互补咬合，缝隙大减。约束已允许，算法要会利用 |
| 2 | **多码套排的码间几何互补** | 大 | v0.3 §5.2；小码裁片塞大码缝隙，8 码套排利用率显著高于单码 |
| 3 | **内部裁片 5–10mm 重合** | 中 | v0.3 §4；单排/双排/裤耳允许单边侵入 10mm，等效缩小面积，填进原本浪费的三角缝。需 NFP 支持"允许穿透 d mm"变体 |
| 4 | **内部裁片大角度旋转** | 中 | 前袋±30°、单排/双排±15°、裤耳±45°，可转角度塞斜缝 |
| 5 | **机头贴后片轮廓嵌套** | 小-中 | v0.3 §1；机头源自后片净版，轮廓匹配可紧贴 |
| 6 | **长时间 SA + 多起点** | 递减 | 93→94% 约 10× 时间，94→95% 约 100×，收益严重递减 |

> 杠杆 1、2 是"免费的午餐"（约束已允许，只是算法要利用），不占用方向 B 的额外工程预算。

#### 2.2.3 结论

- **技术上可以逼近物理上界**，但 **95% 不是普适目标**，必须先估上界。
- **ROI**：93→95% 的研发投入（NFP 重合变体、长时段 SA、套排码组合优化），只有款型稳定 + 产量极大时才摊得平。

## 3. 统一架构：A/B 是同一个 Anytime 引擎的两个时间档

**最重要的判断**：方向 A 和 B 共享同一套核心算法（NFP + BLF + 元启发 + 约束层），区别只是"何时停"。任何带领域约束的排料引擎天然是 **anytime algorithm**——给的时间越多解越好（单调不降），收益递减。

```
┌─ 编排层 ────────────────────────────────────────────┐
│  anytime loop · 时间预算 · 多核并行 · 上界估算        │ ← A/B 的切换开关在这层
├─ 优化层 ────────────────────────────────────────────┤
│  构造启发式(版师经验) + SA/GA 元启发                  │
├─ 约束层（产品护城河，v0.3 规则 = 这层的 spec）─────┤
│  allowed_rotations{0°,180°} · overlap_tol · pair_key │
│  · grain_lock · 内/外分类 · 套排码组合               │
├─ 几何内核层 ─────────────────────────────────────────┤
│  NFP(含重合变体) + IFP + BLF   ← libnest2d / pynest2d │
└──────────────────────────────────────────────────────┘
         ↓ IR（Piece Geometry）是单一数据源
   DXF（切割机） / SVG（前端编辑器）双视图
```

### 3.1 引擎选型（沿用已有调研结论）

- **几何内核**：libnest2d via pynest2d（C++11，PrusaSlicer 在用，契合 Python 原型栈）。
- **约束层自建**：开源引擎（DeepNest / SVGNest / libnest2d）全是 CNC/激光背景、**无服装约束层**。这正是 [排料规则_详细版.md](../material%20sorting/排料规则_详细版.md) 的价值——**它就是约束层的成文 spec**。约束层是产品和护城河。
- **排料结果 = IR 的一个渲染 view**（带每片 transform），导出 DXF + SVG（呼应 Piece Geometry IR 架构）。

### 3.2 约束层的数据契约（裁片 IR 应携带的字段）

| 字段 | 取值（玉林默认） | 来源 |
|---|---|---|
| `grain_locked` | true（水平） | v0.3 §2.1 |
| `allowed_orientations` | `{0°, 180°}` | v0.3 §3.1 |
| `rotation_tol` | 按片：前/后片/后袋 ±1°，腰/机头 ±3°，单排/双排 ±15°，火机袋 ±8°，前袋 ±30°，裤耳 ±45° | v0.3 §3.2 |
| `max_overlap` | 按片：外部 0.4~2mm，内部 5~10mm | v0.3 §4 |
| `pair_key` | 成对类标注，预生成镜像副本 | v0.3 §1 / §2.3 |
| `overlap_semantics` | 沿接触边法线侵入深度 | v0.3 §4 |
| `nest_contour` | 毛版外缝线（含缝份） | v0.3 §5.1 |

## 4. 算法核心说明（三层结构）

呼应行业标配（ET / 富怡 / Gerber / Lectra 都是这个架构）：

1. **几何核心 —— NFP（No-Fit Polygon）**：B 绕 A 贴边滑一圈的参考点轨迹。点在 NFP 内 = 重叠，边界 = 相切合法。配套 IFP（裁片不越门幅的位置集）。把多边形相交判断降维成点在多边形测试。
   - **重合变体（方向 B 杠杆 3 需要）**：把裁片轮廓向内收缩 d mm（d = 对手片的 max_overlap）再算 NFP，即可支持"允许穿透 d mm"的合法重叠。
2. **放置启发式 —— BLF**：沿 NFP 边缘滑到最低最左接触点放下。
3. **元启发优化 —— SA / GA**：搜索"裁片顺序 × 每片姿态"。经典 = 模拟退火（Burke & Kendall 1999）。
   - **姿态模型融入**：每片姿态搜索空间 = `{0°,180°}` × 离散化的公差角度档（如 ±15° 切成 7 档），避免连续空间爆炸。

## 5. 落地路径

| 阶段 | 目标 | 周期 | 产出 |
|---|---|---|---|
| **阶段 0** | 利用率上界估算器 | 1–2 周 | 用现有 M1787 母版 + 无约束近似排料，得出"该款型天花板"。**直接回答 95% 行不行** |
| **阶段 1（方向 A MVP）** | 带约束 anytime 引擎，2min / 93% | 4–8 周 | libnest2d 内核 + 约束层 + 版师启发式 + SVG 拖拽编辑器（人工收尾） |
| **阶段 2（方向 B 深化，按需）** | 逼近上界 | 按需 | NFP 重合变体、套排码组合优化、长时段 SA |

**阶段 1 的 SVG 拖拽编辑器很重要**：工厂真实工作流是"机器排个 90%+ 的底 → 版师微调挤最后几个点"，编辑器 + anytime 引擎互补，就是 A+B 在工厂里的落地形态。

## 6. 结论（5 条）

1. **方向 A 必做、可行性高、商业价值清晰**。20min → 2min 的 10× 加速工程上可达成，核心依赖是"版师经验编码成启发式"——这是壁垒，也是能否达标的关键。
2. **方向 B 别急着定 95%**。先做阶段 0 上界估算器，搞清当前款型物理天花板。95% 对某些款型可达、对阔腿等款型可能根本不存在。
3. **A/B 是同一个 anytime 引擎**，架构上统一，不要做两套。时间预算是它的旋钮。
4. **约束层是产品护城河**，[排料规则_详细版.md](../material%20sorting/排料规则_详细版.md) 就是它的 spec。开源引擎只能当几何内核用。
5. **最大且"免费"的利用率杠杆**：`{0°,180°}` 双姿态 + 多码套排互补——约束已允许，关键是算法要会利用，不占方向 B 额外预算。

## 7. 开放问题与风险

| 项 | 说明 | 缓解 |
|---|---|---|
| 利用率上界未知 | 95% 是否可达取决于款型，目前无数据 | 阶段 0 估算器 |
| 版师隐性经验难完整编码 | 决定方向 A 能否稳定到 93% | 版师联合创始人深度参与，迭代抽取规则 |
| 套排码组合爆炸 | 8 套 × 每套 18 片，码号选择本身是优化变量 | 先用版师常规组合做启发式，再逐步优化 |
| 裤耳长条切段建模 | 长条 + 切段约束（单边角 ≤10mm）的几何处理 | 阶段 1 后期细化 |
| libnest2d 重合支持 | 原生 NFP 不支持"允许穿透 d mm" | 阶段 2 自研重合变体 NFP |
