**关键不变量（US-005 立，后续故事不得破坏）**：
1. **ControlPanelStartPayload.seed_count 是已 clamp 的最终值**（1 或 [2,6]）—— App 直接
   `for i<seed_count` 启 N 个 WS，不再做边界检查。
2. **ConvergenceCurve 命令式 innerHTML** —— React 仅渲染 `<svg ref/>`；所有子节点（line/text/
   circle/path/g.legend）通过 `svg.innerHTML = out` 一次性写入。**不要改成 JSX**，否则每帧 diff
   开销爆炸。采样、配色、字面量与旧 app.js drawCurve 字节级一致（单测逐字段对比）。
3. **sampleFrames 末帧强制纳入** —— `pts[last] !== frames[last]` 则 push。step = floor(n/400)，
   n<=400 时 step=1 全量。改这个算法必须同步 `__tests__/ConvergenceCurve.test.tsx` 4 个采样用例。
4. **App.all-done 检测用 ref，不用 state** —— `doneCountRef.current += 1; if (< totalSeedsRef) return;`
   闭包陈旧风险靠 ref 规避；setStatus 汇总含 best（runs.reduce 比 finalDensity）。
5. **useRafThrottle(seeds.length>0) 不在 solving=false 时停** —— 求解结束后曲线 / NestLabel 仍
   需要重绘最终态；下次 start() 才会 runRegistry.clear + setSeeds([]) 间接停掉。
