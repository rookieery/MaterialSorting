- 同步 `.docs/technical/agent-api-reference.md`（US-005 前端契约不变量 #6）

**关键决策**:
1. **uploadStore 是单一真相源**（与 runRegistry 高频 mutable 相反）—— 解析结果低频，doc/activeSize/error 全部进 React state，UI 订阅触发 reconciliation 同步。
2. **状态过渡由 hook 直接 `useUploadStore.setState({...})` 写入，不暴露成 store 公开 action** —— store 公开 API 仅 reset/setSize，避免业务组件误触发跳变。
3. **防连击双重防护**：uploadingRef（立即生效）+ status==='uploading'（store 状态）。ref 必需 —— setState 异步，第二次连击会在 setState 调度前进 hook body。
4. **FormData 不手设 Content-Type** —— 浏览器需自动加 boundary，手设会丢导致后端 python-multipart 解析失败。useParseDxf.test.tsx AC#1 有断言。
5. **activeSize 默认 = `doc.sizes[0].size ?? null`**（后端按数值升序、null 殿后，sizes[0] 是最小码）。
6. **错误不抛、不 rethrow** —— useParseDxf try/catch 兜底，所有错误（网络错/JSON 错/4xx/5xx）统一进 uploadStore.error，UI 自取。
7. **doc/activeSize 在失败时不主动清** —— uploading 时清 error 但保留 doc/activeSize 避免切 uploading 时 UI 闪烁；reset() 才彻底清零。
